Scoping Review는 언제 하는가

특정 주제를 다룬 연구가 어디에 얼마나 있고, 어떤 개념·방법·대상을 사용했는지 체계적으로 파악하는 데 적합하다. 개념 정의가 문헌마다 다르거나, 연구가 특정 집단이나 환경에 집중되어 있는지 알고 싶을 때 특히 유용하다.

연구질문이 묻는 바에 따라 Review의 설계를 정합니다.

PCC와 Protocol

제목, 목적, Review Question, Eligibility Criteria의 범위를 맞춘다. 아래처럼 PCC를 정한 뒤, 팀원이 논문 한 편을 읽고 같은 기준으로 판단할 수 있도록 경계 사례까지 문장으로 써 둔다.

항목가상 설계
Population병원에서 근무하는 간호사. 여러 직종이 함께 포함된 연구는 간호사 관련 결과를 별도로 확인할 수 있을 때 포함한다.
ConceptCollegial Solidarity의 정의, 구성요소, 측정. Peer Support 등 인접 개념은 후보 검색어로 검토하고, 포함 여부는 원문에서 간호사 간 상호 지원이나 공동 대응을 어떻게 다루는지에 따라 판단한다. 관리자 지원만 다룬 자료는 이 예시 범위에서 제외한다.
Context병원 근무 환경. 국가나 병동 유형을 제한할지는 질문에 따라 정한다.
Sources of Evidence정의와 측정을 파악할 수 있는 양적·질적·혼합방법 연구를 고려한다. 척도 개발 연구, 개념 분석, Grey Literature를 포함할지는 각각의 역할을 정해 명시한다.

Review Question 예시　병원 간호사 문헌에서 Collegial Solidarity는 어떻게 정의되고 측정되며, 어떤 병원 환경과 간호사 집단에서 연구되었는가?

Protocol에 남길 사항　기존 Review와 비교한 연구 필요성, PCC와 자료 유형, 언어·기간 제한의 근거, 검색원과 검색식, Screening 및 불일치 처리 방법, Data Charting 항목, 분석과 결과 제시 계획을 사전에 적는다. 진행 중 변경 사항은 결정 날짜와 이유를 남겨 최종 논문에 보고한다.

제목과 Introduction 쓰기

Protocol 제목에는 a scoping review protocol을 넣고, 최종 논문 제목에는 a scoping review를 넣습니다. Introduction에는 핵심 개념의 정의, PCC 범위를 정한 이유, 이 Review가 필요한 이유를 적습니다. 기존 Scoping Review와 Systematic Review를 예비 검색한 날짜와 검색원을 기록하고, 유사 Review가 있다면 이번 질문이 어떤 범위를 추가하는지 설명합니다. 마지막에 PCC에 맞는 Review Objective를 제시합니다.

Search와 Screening

세 단계로 Search 설계

  1. 주제에 적합한 Database 최소 두 곳에서 제한적으로 탐색한다. 간호 주제라면 CINAHL과 MEDLINE을 후보로 검토하고, 관련 논문의 제목·초록 표현과 Index Terms를 확인한다.
  2. 확인한 Keywords와 Index Terms를 각 Database 문법에 맞춰 적용한다. 예시 출발점은 (nurs* OR nursing staff) AND (collegial solidarity OR professional solidarity OR peer support OR coworker support)이며, 실제 검색식은 관련 논문이 검색되는지 확인해 조정한다. PCC를 모두 검색식에 넣었을 때 관련 문헌이 누락되는지도 점검한다.
  3. 선정한 자료군의 참고문헌을 확인한다. 포함 문헌 전체를 볼지, Full-text Screening에 오른 문헌까지 볼지 Protocol에 적고, 필요한 경우 Grey Literature 검색원을 정한다.

Database와 플랫폼, 검색일, 검색식, 적용 제한, 검색 건수를 저장한다. Protocol 부록에는 최소 한 주요 Database의 전체 검색식을 싣는다. 검색어를 추가했다면 언제 어디서 다시 검색했는지 기록한다.

JBI §11.2.5 · PDF 420쪽 · 최종 원고의 요건은 상세 검색식 Checklist를 확인하세요.

두 단계로 Screening

중복 제거 후 Title/Abstract Screening과 Full-text Screening을 진행한다. 각 단계에서 두 명 이상이 독립적으로 판정하고, 의견 차이는 합의 또는 제3의 Reviewer 판정으로 해결한다. 제목과 초록만으로 판단하기 어려운 경우 전문을 확인한다. 전문 미확보 건은 별도로 집계하고, 전문을 읽고 제외한 자료에는 제외 사유를 남긴다.

JBI가 제시하는 Pilot 예시는 무작위 25건을 팀 전체가 검토하고, 차이를 논의해 기준을 보완한 뒤, 일치율 75% 이상에서 본 Screening을 시작하는 방식이다.

JBI §11.2.6 · PDF 421쪽 JBI §11.3.7.1–11.3.7.2 · PDF 435–436쪽

포함 문헌 목록은 Data Charting으로 넘기고, 검색 건수와 전문 제외 사유는 최종 원고용으로 보관합니다.

Data Charting

Review Question에 답하는 데 필요한 열부터 만든다. JBI는 Protocol 단계에서 양식을 초안으로 만들고, 팀원 최소 두 명이 문헌 두세 편을 대상으로 적용해 보도록 제안한다. 추출·확인 방식과 양식 변경 사항을 기록하고, 새 항목을 추가했다면 이미 처리한 문헌에도 같은 기준을 적용한다.

질문기록할 항목 예시결과에 쓰는 방식
어떤 연구가 있는가?문헌 ID, 저자·연도, 국가, 병동, 연구설계, 대상과 표본연도·환경·설계별 건수, 포함 문헌 특성표
개념을 어떻게 정의하는가?저자가 사용한 용어, 명시적 정의 여부, 정의 문장과 페이지, 구성요소정의 비교표, 반복적으로 등장하는 구성요소
어떻게 측정하는가?도구명, 하위영역, 응답자, 해당 연구가 보고한 측정 특성측정 도구별 비교표

보고가 없는 항목과 적용할 수 없는 항목의 기록 규칙을 정한다. 같은 연구에서 나온 여러 출판물을 함께 다룬다면 문헌 ID와 연구 ID를 연결해 집계 단위를 명확히 한다.

결과 분석과 논문 보고

  • Analysis　연도·국가·환경·방법별 빈도로 문헌 분포를 보여준다. 정의를 비교할 때는 Descriptive Content Analysis를 사용해 원문에 나타난 범주를 정리할 수 있다. 한 문헌에 여러 범주를 부여했다면 표에서 중복 집계와 분모를 설명한다.
  • Critical Appraisal　JBI 2020에서 이 단계는 필수가 아니다. 연구 목적상 실시한다면 이유, 도구, 결과를 어떻게 활용할지 명시한다.
  • Results　PRISMA Flow Diagram으로 검색·중복 제거·선정 과정과 전문 제외 사유를 보여준다. 포함 문헌 특성표에 이어 Review Question별 결과를 제시한다.
  • Discussion　어떤 집단과 환경에서 근거가 집중되거나 드물었는지 설명한다. 예를 들어 “검색 범위에서 외래 간호사를 다룬 연구가 적었다”는 진술은 문헌 분포에 대한 해석이다. 연구 수만으로 개입 효과나 근거의 확실성을 판단할 수 없다.
  • PRISMA-ScR　최종 원고에서 검색원, 검색식, 선정 과정, Data Charting과 결과 제시가 빠짐없이 보고되었는지 확인한다. JBI는 연구 수행 방법을, PRISMA-ScR은 논문 보고 항목을 안내한다.

JBI §11.2.8–11.2.9 · PDF 423–426쪽 JBI §11.3.8.1–11.3.8.3 · PDF 440–442쪽 JBI §11.3.9–11.3.10 · PDF 443–444쪽

Results와 Discussion을 작성한 뒤, 각 원고 항목과 Appendix에 필요한 기록이 있는지 확인합니다.
